# BELTEI IU PORTAL

BELTEI IU Portal is a comprehensive web-based academic management platform developed for BELTEI International University. The system provides a centralized digital environment for students, lecturers, faculty staff, and administrators to manage academic activities, communication, and institutional services efficiently.

## Overview
The portal streamlines university operations by offering a secure and user-friendly platform for accessing academic information, managing student records, handling course registration, monitoring attendance, publishing announcements, and facilitating communication between all stakeholders.

## Key Features
*	Student profile management
*	Course registration and enrollment
*	Class schedule viewing
*	Attendance tracking
*	Examination results and transcripts
*	Tuition fee information and payment records
*	Academic notifications and announcements
